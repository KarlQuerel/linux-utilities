# Linux Utilities

Collection of Linux utility scripts to automate common tasks.

## Quick Start

```bash
chmod +x linux-utilities.py
./linux-utilities.py
```

**No dependencies required!** Uses only Python standard library.

## Utilities

- **🚀 Auto-Update Setup** - Configure automatic APT updates via systemd (on boot or daily schedule)
- **🧹 Disk Cleanup** - Remove APT cache, old logs, temp files, and unused packages
- **📊 System Report** - Display system information (OS, CPU, memory, disk, network)

**Note:** Auto-Update and Disk Cleanup require root privileges. The tool will prompt for sudo when needed.

## Usage

Run `./linux-utilities.py` and select from the interactive menu. Press `ESC` to exit anytime.
